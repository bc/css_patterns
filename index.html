01 · The system

Pick a color. Pick a pattern.

Everything is derived from --c with color-mix() and relative color syntax — no per-color CSS.

What one color becomes

--cyour input
--pprimary bg
--saccent
--s-histrong accent
--scsame-hue accent
--s32× shifted
--inktext color

Three strengths

subtle
medium
bold

Use it

<!-- 1. link the file -->
<link rel="stylesheet" href="textures.css">

<!-- 2. pattern + strength + one color -->
<div class="tex tex-hex tier-medium c-rose">
  <h2>Big bold text</h2>
</div>

<!-- any hex works too -->
<div class="tex tex-aurora" style="--c:#0d9488">…</div>

<!-- stack a mask pattern on a blend -->
<div class="tex tex-aurora tex-plus">…</div>

/* knobs */
--c     /* the one color              */
--hue   /* accent hue shift, 0 = mono */
--k     /* scale: .size-sm / lg / xl  */
--p --s /* override derived colors    */
02 · Subtle

Barely there.

Fine hairlines, tiny dots, paper grain. Safe behind paragraphs of text. Click any card to copy its classes.

03 · Medium

Clearly patterned.

Stripes, checks, honeycomb, scales. The all-rounder for cards, headers and tiles.

04 · Bold

Make a statement.

Big shapes and a stronger accent — still pale enough for black, heavy, oversized type.

05 · Blends

Gradients × patterns × grain.

Mesh gradients, aurora glows, film grain via background-blend-mode, fades that dissolve a pattern into the background.

06 · Combos

Stack them.

Mask patterns (plus, hex, stitch…) live on ::before, so they layer over any gradient or blend.

07 · Palette

Same class. Sixteen colors.

Each tile below is identical markup — only --c changes. Top: tex-hex tier-medium. Bottom: tex-aurora.

08 · In use

On real components.

Everything here is a single .tex class combo. Text stays crisp because the surfaces stay light.
